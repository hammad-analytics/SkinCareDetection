# Mobile Testing Checklist

Test at 320, 375, 390, 412, 768, 1024, and 1366px widths.

Manual device checklist:
- Android camera capture
- iPhone camera capture
- Gallery upload
- Large portrait image
- Rotated EXIF image
- Low-light image
- Blurry image
- Slow network retry
- Result page readability
- Scan history access
- Logout and protected route behavior
